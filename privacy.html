Privacy Policy

Last updated: 20 November 2026

ShortsLab Publisher is a private tool used only by the owner of the connected YouTube channels to upload their own videos.

Data we access

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos and set their titles, descriptions and privacy settings on the owner's channels. It does not access data of any other user.

Storage

OAuth tokens are stored only on the owner's private server and are never sold, shared or transferred to third parties. No analytics or advertising data is collected.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
